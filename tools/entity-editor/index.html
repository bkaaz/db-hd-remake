States

Read-only view of states.json. States are hand-authored for now; this tab shows the machine and flags broken references (unknown animation, unknown target state, unknown trigger).

Sounds

This entity's own sounds, data/entities/<name>/sounds.json — its voice. Everything a punch or a landing sounds like belongs to the game, not to a fighter: that is the Global sounds tab. An id defined in both is an error.

Global sounds

The game's sound bank, data/audio/sounds.json — swings, impacts, blocks, landings, shared by every fighter. Pick one to edit it; the list at the bottom is for running an ear down every sound. Which state plays a sound is still typed into states.json by hand.
